# Clínica Odontológica Sorriso Pleno — Site Institucional

Projeto piloto desenvolvido para demonstração de boas práticas de **HTML5 Semântico**, **CSS3 Responsivo** e **Deploy Contínuo (CI/CD)** na disciplina de CODING — Engenharia de Software.

## Estrutura do Projeto
- `index.html`: Marcação semântica sem estilos inline.
- `css/style.css`: Estilização modular com variáveis `:root`, Flexbox, CSS Grid e Media Queries.
